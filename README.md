# FIT Part 2 - Cyclic Linear Code over GF(2)

## 1. Thông tin bài tập

Bài tập thuộc Part 2 của môn Fundamentals of Information Theory.

Yêu cầu:

- Xây dựng lớp Bit.
- Xây dựng lớp Vector nhị phân / từ mã.
- Xây dựng lớp đa thức trên GF(2).
- Xét mã vòng tuyến tính C(n, k) có đa thức kiểm tra h(x) cho trước.
- Xác định:
  - Khoảng cách mã tối thiểu.
  - Khả năng phát hiện lỗi.
  - Khả năng sửa lỗi của bộ mã.
